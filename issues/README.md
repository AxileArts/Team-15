# Issues

Analysis plans and experiment cards are stored here as markdown files, one file per item.

- File name: `NNN-short-title.md` (e.g. `001-baseline-linear-regression.md`)
- First line states the type: `Type: analysis-plan` or `Type: experiment`
- Add `Status: ready-for-agent` once the item is specified well enough for an agent to work on it
